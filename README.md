# MarkBox

Windows 托盘常驻小工具：快捷键唤起微信截图式圈选，在屏幕上留下一个不挡任何操作的边框标记——用来标记"我要点的位置"。

- 圈选快捷键：`Alt+M`（松开鼠标后可拉宽/拉高/移动，✓ 或回车确认）
- 清除快捷键：`Alt+Shift+M`

状态：设计阶段，见 [docs/superpowers/specs/2026-09-03-markbox-design.md](docs/superpowers/specs/2026-09-03-markbox-design.md)

技术栈：Tauri 2 (Rust) + Vanilla TypeScript + Vite 多入口
