# MarkBox 设计文档

日期：2026-09-03
状态：已实现

## 一句话描述

Windows 托盘常驻小工具：从主界面或托盘一键唤起微信截图式圈选，在屏幕上留下一个**不挡任何操作的边框标记**，用来标记"我要点的位置"。

## 目标与非目标

**目标**
- 主窗口/托盘菜单一键唤起全屏圈选（微信截图式：整屏压暗，选区透明）
- 两段式操作：先圈选、后调整（拉宽/拉高/移动）、显式确认
- 确认后留框：仅边框可见，中间透明、鼠标穿透、始终置顶、不抢焦点、不进任务栏
- 单框替换语义；随时可清除（主窗口/托盘）
- 边框外观可配置

**非目标**
- 不做截图、标注、画笔、文字（只留框）
- 不做开机自启
- 不做全局快捷键（所有操作走主界面/托盘）
- 不做多框并存
- 不做 macOS/Linux 发布（但开发期在 macOS 上可运行调试）

## 技术栈

| 层 | 选型 | 理由 |
|---|---|---|
| 框架 | Tauri 2 (Rust) | 点击穿透/透明置顶窗/托盘均为一等 API；mac 上 `tauri dev` 可直接调试交互，Windows 出包；产物小 |
| 前端 | Vanilla TypeScript + Vite 多入口 | 三个窗口 UI 极薄（合计几百行），UI 框架在此体量下是负担 |
| 持久化 | JSON（Tauri app config dir） | 设置项少，无需数据库 |

## 术语

- **圈选（draft）**：按住左键拖出矩形的过程
- **调整（adjusting）**：松开鼠标后、点击确认前的阶段；框带手柄与确认按钮，仍可修改
- **确认（confirm）**：点击 ✓ 按钮或按回车，圈选流程结束
- **标记框（mark）**：确认后留下的那个点击穿透边框窗口

## 交互规格

### 主流程

1. 点击主窗口"**开始圈选**"按钮或托盘菜单"**圈选**" → 全屏压暗覆盖层出现（每个显示器一个实例），主窗口自动隐藏
2. **圈选**：按住左键拖出矩形，实时显示尺寸标签（如 `320 × 180`，物理像素）
3. 松开鼠标 → 进入**调整阶段**（整屏保持压暗，选区内透明，确认或取消时覆盖层才关闭）：
   - 框上出现 8 个手柄（四角 + 四边），拖动手柄拉宽/拉高
   - 框内按住拖动可整体移动位置
   - 框右下角外侧出现 **✓ 确认按钮**；若框贴近屏幕底部则翻转到框上方
   - 按 **Enter** 等同点击确认
4. **确认** → 覆盖层全部关闭，标记框窗口出现：只有一圈边框（默认 3px、`#FF4D4F`、直角，可配置），中间完全透明、鼠标穿透、始终置顶

### 取消与清除

- 圈选或调整的**任何阶段**按 **Esc** 或**右键** → 整个操作取消，不留任何框
- 取消一轮新圈选时，**已确认的旧框原样保留**（替换发生在新框确认的那一刻）
- 点击主窗口"**清除标记**"按钮或托盘菜单"**清除标记**" → 清除当前已确认的标记框

### 替换语义（单框）

- 屏幕上最多存在一个已确认标记框
- 开始新圈选时旧框保持可见；新框确认时替换旧框

### 误触保护

- 松开鼠标时若选区任一边 < 5px → 视为误触，操作取消，覆盖层关闭
- 手柄调整阶段强制最小尺寸 10×10（拖不小于此值）

## 窗口架构（3 个前端入口）

| 入口 | 窗口 | 生命周期 |
|---|---|---|
| `main.html` | 主窗口（操作按钮 + 外观设置） | 应用启动即创建并显示；关闭即隐藏到托盘常驻，退出走托盘菜单 |
| `overlay.html` | 圈选覆盖层（每显示器一个实例） | 唤起时创建，确认/取消后销毁 |
| `mark.html` | 标记框 | 确认时创建；替换/清除时销毁重建/销毁 |

### 主窗口内容

- 操作区：**开始圈选**、**清除标记**（无标记时置灰）两个按钮
- 外观设置区：边框颜色、粗细（1–10px）、圆角（0–16px），保存即生效（热更新到现存标记框）

### 覆盖层窗口属性

`fullscreen 逻辑（position/size 对齐各显示器物理像素）`、`decorations: none`、`always_on_top`、`skip_taskbar`、`transparent`、`resizable: false`

### 标记框窗口属性（核心）

`decorations: none`、`transparent`、`always_on_top`、`skip_taskbar`、`focusable: false`（不抢焦点、不出现在 Alt-Tab）、`resizable: false`、**`set_ignore_cursor_events(true)`**（点击穿透——边框与透明区域全部穿透）

## Rust 侧职责

- 托盘图标与菜单：圈选 / 清除标记 / 显示主窗口 / 退出
- `tauri-plugin-single-instance`：防止多开（再次启动时唤起已有实例的主窗口）
- 圈选/标记窗口的创建、定位（物理像素换算）、属性设置、销毁
- 设置读写（JSON）与变更广播（外观热更新到现存标记框）
- 覆盖层间协调：确认/取消在 Rust 侧销毁全部覆盖层（无 overlay 间事件）

## 设置项

| 项 | 默认 |
|---|---|
| 边框颜色 | `#FF4D4F` |
| 边框粗细 | 3px（范围 1–10） |
| 边框圆角 | 0px（范围 0–16） |

## 错误处理

- 设置文件损坏/缺失 → 回退默认值并重建
- 多显示器热插拔（圈选进行中拔掉屏幕）→ 关闭全部覆盖层，操作取消
- 非预期的 overlay 崩溃 → Rust 侧兜底清理所有覆盖层窗口

## 多显示器与 DPI

- 每个显示器一个覆盖层实例；标记框建在选区所在显示器上
- 所有坐标按**物理像素**换算（PerMonitorV2 DPI aware）
- 选区/调整过程中 clamp 在所属显示器范围内

## 测试策略

- **Rust 单元测试**：显示器相交判定（坐标）、设置读写与默认值回退；CSS↔物理像素换算在前端，由 Vitest 纯函数测试覆盖
- **前端纯函数测试**（Vitest）：手柄拖动的几何计算（拉角/拉边/移动/clamp/最小尺寸）
- **手动验收清单**（Windows 机）：主界面/托盘唤起→圈选→调整→确认→穿透验证（框上移动鼠标、点击、滚轮均不受影响）→替换→清除→Esc 各阶段取消
- macOS `tauri dev` 用于日常交互调试（穿透/置顶在 mac 上行为一致）
